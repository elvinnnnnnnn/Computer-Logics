Error Investigation
Error message: (Uncaught SyntaxError: missing ) after argument list)
File name: script.js
Line number: (5)
What caused the error:** I removed the closing quotation mark on a string,
so JavaScript could not tell where the text ended.
How I fixed it: I added the missing quotation mark back, saved the file,
and reloaded the page. The console then loaded with no errors.
